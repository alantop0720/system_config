# cmd 工具 安装配置使用说明

更新日期：2026-09-06

## 一、简介

`cmd` 是一个轻量级 Linux 运维菜单工具（C99 单文件实现），通过读取 `/opt/cmd/` 下的菜单定义文件，把常用运维命令做成带编号的菜单，支持两种运行方式：

- 交互式：`cmd dhcp` 弹出菜单，手动输入序号执行
- 直接执行：`cmd dhcp 1` 命令行带序号参数，直接运行对应菜单项，适合脚本调用和熟练后快速操作

## 二、目录结构

### 服务器上的部署位置

| 路径 | 说明 |
|------|------|
| `/usr/local/bin/cmd` | 编译安装后的可执行程序 |
| `/opt/cmd/<菜单名>` | 菜单定义文件（纯文本，如 `dhcp`、`firewalld`） |
| `/opt/cmd/readme` | `cmd` 无参数运行时显示的帮助文件 |
| `/opt/cmd/sh/` | 菜单命令可能调用到的辅助脚本 |
| `/opt/cmd/src/c/` | 源码目录（编译安装在这里进行） |

### 仓库中对应的源文件

| 仓库路径 | 说明 |
|----------|------|
| `cmd/src/c/cmd.c` | 程序源码（单文件） |
| `cmd/src/c/Makefile`、`CMakeLists.txt`、`install.sh` | 构建脚本 |
| `cmd/<菜单名>` | 各菜单定义文件（dhcp、disk、docker、firewalld、ip、net 等 40 余个） |
| `cmd/readme` | 帮助文件 |
| `cmd/sh/*.sh` | 辅助脚本 |
| `cmd/ubuntu_cmd/` | Ubuntu 系统变体的菜单文件（dc、net） |

## 三、安装

### 环境要求

- Linux 服务器（Debian/Ubuntu 等已验证）
- gcc（C99）

### 安装步骤（Makefile 方式，推荐）

首次部署时，先把源码和菜单文件同步到服务器对应路径（源码在 `/opt/cmd/src/c`，菜单文件在 `/opt/cmd/`），然后：

```bash
cd /opt/cmd/src/c
make            # 编译，gcc cmd.c -o cmd
make install    # 拷贝 cmd 到 /usr/local/bin/cmd，并设置 /opt/cmd/sh/ 脚本权限
```

### 安装步骤（CMake 方式，可选）

```bash
cd /opt/cmd/src/c
bash install.sh   # 等价于 mkdir build && cd build && cmake .. && make -j$(nproc) && make install
```

### 修改源码后更新

```bash
cd /opt/cmd/src/c
make && make install
```

注意：只修改菜单定义文件（`/opt/cmd/<菜单名>`）不需要重新编译，`cmd` 每次运行都会重新读取；只有修改 `cmd.c` 源码后才需要重新编译安装。

## 四、配置

### 菜单文件格式

每个菜单文件是一个纯文本文件，**每 3 行描述一个菜单项**：

```
第 1 行：菜单项描述（菜单里显示的文字）
第 2 行：flag（1 = 直接执行，0 = 自定义参数，可输入变量）
第 3 行：要执行的命令
```

以 `dhcp` 菜单文件为例：

```
查看dhcp服务状态
1
systemctl status isc-dhcp-server
重启服务
1
systemctl restart isc-dhcp-server
查看租约文件dhcpd.leases
1
vim /var/lib/dhcp/dhcpd.leases
编辑dhcp配置文件
1
vim /etc/dhcp/dhcpd.conf
显示客户端
1
dhcp-lease-list
检查dhcp配置文件是否有语法问题
1
dhcpd -t -cf /etc/dhcp/dhcpd.conf
```

格式限制：最多 100 个菜单项，每行最长 1024 字符，换行符使用 LF（Linux 格式，Windows 下编辑时注意不要保存成 CRLF）。

### flag=0 的交互参数用法

第 3 行命令中可以用 `[名称]` 占位，运行时会逐个提示输入，输入值会替换进命令。以 `firewalld` 菜单为例：

```
开启端口
0
firewall-cmd --permanent --zone=public --add-port=[21]/tcp && firewall-cmd --reload
```

运行该项时会提示 `请输入 21:`，输入的端口号会替换 `[21]` 后执行。

### 新增 / 修改菜单

1. 在仓库 `cmd/` 目录新建一个无扩展名的文本文件（文件名即子命令名，如 `myapp`）
2. 按上述 3 行一组格式填写菜单项
3. 拷贝到服务器：`cp myapp /opt/cmd/myapp`
4. 之后即可使用 `cmd myapp` / `cmd myapp 1`

删除菜单项：直接编辑或删除 `/opt/cmd/` 下对应文件即可，立即生效。

## 五、使用

### 三种运行方式

```bash
cmd                # 显示 /opt/cmd/readme 帮助，并列出 /opt/cmd 下所有可用菜单
cmd <菜单名>        # 交互式：打印菜单，提示"请输入要执行的序列号"，手动输入序号执行
cmd <菜单名> <序号>  # 直接执行：跳过输入提示，直接运行对应菜单项（新功能）
```

### 直接执行示例（dhcp 菜单）

| 命令 | 执行内容 |
|------|----------|
| `cmd dhcp 1` | 查看dhcp服务状态（systemctl status isc-dhcp-server） |
| `cmd dhcp 2` | 重启服务（systemctl restart isc-dhcp-server） |
| `cmd dhcp 3` | vim 查看租约文件 dhcpd.leases |
| `cmd dhcp 4` | vim 编辑配置文件 dhcpd.conf |
| `cmd dhcp 5` | 显示客户端（dhcp-lease-list） |
| `cmd dhcp 6` | 检查配置文件语法（dhcpd -t -cf /etc/dhcp/dhcpd.conf） |

执行时菜单列表仍会显示，随后打印将要执行的命令并运行，便于确认和留档。

### 说明与错误提示

- 直接执行方式只识别第 2 个参数，序号超出范围或不是数字（如 `cmd dhcp 99`、`cmd dhcp abc`）会提示"无效的序列号"并退出
- flag=0 的菜单项用直接执行方式调用时，仍会提示输入 `[名称]` 变量值
- 菜单项调用的外部命令需要服务器上已安装，否则会报 `sh: 1: xxx: not found`

## 六、常见问题（FAQ）

**1. 执行菜单项提示 `sh: 1: xxx: not found`**

菜单第 3 行命令所依赖的程序在服务器上未安装。例如 `dhcp-lease-list` 需要先安装提供该命令的软件包（Debian/Ubuntu 为 `apt install isc-dhcp-server`），安装后重新执行即可。

**2. 提示"无法打开文件"**

`/opt/cmd/` 下不存在对应的菜单文件，或子命令名拼写错误。运行 `cmd` 查看可用菜单列表。

**3. 修改了源码但没有生效**

需要重新编译安装：`cd /opt/cmd/src/c && make && make install`。只改菜单文件则无需重编译。

**4. 菜单显示乱码或解析错乱**

检查菜单文件换行符是否为 LF、是否严格按"描述/flag/命令"三行一组的顺序书写（三行顺序错乱会导致该项执行错误命令）。
